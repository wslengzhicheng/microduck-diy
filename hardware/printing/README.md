# 3D 打印指南

本页说明如何从上游项目获取 STL 文件并打印 Microduck 的所有结构件。

---

## 获取 STL 文件

Microduck 的 3D 模型以 `.3mf` 格式发布在上游仓库：

- 文件：[`microduck3D打印.3mf`](https://github.com/AI-FanGe/Microduck-build-tutorial)（位于仓库根目录）

### 提取步骤

1. 下载上游仓库中的 `microduck3D打印.3mf` 文件
2. 使用切片软件（推荐 PrusaSlicer、OrcaSlicer 或 Bambu Studio）打开 `.3mf` 文件
3. 在切片软件中可以看到所有部件的 3D 模型和预设的打印方向
4. 如需单独导出 STL：在切片软件中选中单个部件 → 右键 → 导出为 STL

> [!TIP]
> `.3mf` 文件通常已经包含了推荐的打印方向和支撑设置。直接使用 `.3mf` 打印是最简单的方式。

---

## 打印参数

| 参数 | 推荐值 |
| :--- | :--- |
| 材料 | PLA（推荐）或 PLA+ |
| 层高 | 0.2mm |
| 壁厚 | 3–4 层 |
| 填充率 | 20–30% |
| 支撑 | 按部件需要（见下表） |
| 热床温度 | 60°C |
| 喷嘴温度 | 200–215°C |

> [!NOTE]
> 上述为通用 PLA 参数，请根据你的打印机和耗材品牌微调。

## 打印建议

1. **先打印一个小部件测试**：建议先打印一个脚部或小关节件，确认尺寸和配合精度
2. **注意公差**：舵机安装孔和轴承位置需要适当的过盈/间隙配合。如果偏紧，可用锉刀微调
3. **后处理**：
   - 去除支撑材料
   - 用砂纸（400 目）打磨配合面
   - 检查螺丝孔是否通畅
4. **打印方向**：优先按 `.3mf` 中的预设方向打印，这通常会优化强度和减少支撑
5. **颜色**：功能上无要求，选择你喜欢的颜色。经典配色为白色主体
