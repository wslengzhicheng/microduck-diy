## 硬件架构概览

Microduck 的硬件核心由以下部分组成：

```
┌─────────────────────────────────────────────┐
│              成品 6V 可充电电池               │
│                    │                         │
│              ┌─────┴─────┐                   │
│              │  电源开关   │                   │
│              └─────┬─────┘                   │
│         ┌──────────┼──────────┐              │
│         ▼          ▼          ▼              │
│   ┌──────────┐ ┌────────┐ ┌────────────┐    │
│   │ 5V 稳压器 │ │OpenRB  │ │ XL330 ×14  │    │
│   │  → Pi    │ │  -150  │ │ 舵机总线    │    │
│   └──────────┘ └───┬────┘ └────────────┘    │
│                    │USB                      │
│              ┌─────┴─────┐                   │
│              │ Pi Zero   │                   │
│              │   2W      │◄── BNO08x IMU     │
│              └───────────┘    (I2C)          │
└─────────────────────────────────────────────┘
```

- **Raspberry Pi Zero 2W** — 主控制器，运行 ONNX 行走策略
- **ROBOTIS OpenRB-150** — 通过 USB 连接 Pi，驱动 Dynamixel 舵机总线
- **Dynamixel XL330-M288-T ×14** — 双腿 10 个 + 头颈 4 个
- **BNO08x IMU** — 通过 I2C 提供姿态数据
- **成品 6V 可充电电池** — 主电源

详细接线请参考 [接线指南](../docs/wiring-guide/README.md)。
