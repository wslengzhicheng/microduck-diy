# 组装指南

Microduck 双足机器人的完整分阶段组装指南。配合 [物料清单](../../hardware/bom/README.md)、[接线指南](../wiring-guide/README.md) 和 [打印指南](../../hardware/printing/README.md) 一起使用。

---

## 阶段总览

| 阶段 | 目标 | 预计时间 | 参考文档 |
| :--- | :--- | :--- | :--- |
| 1. 备料与打印 | 物料齐全 + 打印件就绪 | 1–2 次工作时段 | [BOM](../../hardware/bom/README.md), [打印指南](../../hardware/printing/README.md) |
| 2. 台面接线 | 完成 90% 电气连接 | 1 次工作时段 | [接线指南](../wiring-guide/README.md) |
| 3. 预装配关节 | 舵机装入壳体，线槽走线 | 1 次工作时段 | 本指南 (阶段 3) |
| 4. 主体装配 | 电子器件装入躯干，布线整理 | 1–2 次工作时段 | 本指南 (阶段 4) |
| 5. 校准与调试 | 舵机 ID 验证、IMU 检测 | 1 次工作时段 | [调试指南](../commissioning/README.md) |
| 6. 合盖与首次行走 | 安装外壳，手扶测试行走 | 0.5 次工作时段 | 本指南 (阶段 6) |

> [!TIP]
> 把每个阶段当作一个里程碑。每完成一个阶段，拍一张进度照片并记录遇到的问题，这样后续排错会轻松很多。

---

## 阶段 1：备料与打印

**目标：** 在开始任何焊接或装配之前，确保所有物料和打印件已就绪。

**你需要：**
- [物料清单 (BOM)](../../hardware/bom/README.md) — 核对电子器件、电源、紧固件和工具
- [打印指南](../../hardware/printing/README.md) — 打印所有结构件

**操作步骤：**

1. 按 BOM 逐项核对物料，确认无遗漏
2. 从上游仓库下载 `microduck3D打印.3mf`，打印所有结构件
3. 打印件后处理：去除支撑、打磨配合面、检查螺丝孔
4. 舵机 ID 设置和零位对齐已移至**阶段 3-A**统一完成（支持 U2D2 或 OpenRB-150 两种接口）

> [!IMPORTANT]
> **强烈建议在装机前设置好所有舵机 ID 并对齐零位。** 装入壳体后再设置 ID 或重新对齐舵盘非常困难。详见本指南阶段 3-A 和 [调试指南](../commissioning/README.md)。

### 阶段 1 检查清单

- [ ] 所有 3D 打印件已打印并后处理完毕
- [ ] 14（或 15，含嘴部可选）个 XL330 舵机到手，通电测试确认无损坏
- [ ] Pi Zero 2W、OpenRB-150、BNO08x IMU 到手
- [ ] 6V 电池、电源开关、稳压模块到手
- [ ] M2/M2.5 螺丝、Dynamixel 线缆、分线器、工具齐全
- [ ] 耗材就位：硅胶线、热缩管、扎带、焊锡

## 阶段 2：台面接线 (90%)

**目标：** 在工作台上完成大部分电气连接，减少在机体内部操作的难度。

1. 打开 [接线指南](../wiring-guide/README.md)，通读电源和舵机总线部分
2. **电源系统：**
   - 焊接电池 → 开关 → OpenRB-150 VIN/GND 的电源线
   - 焊接电池 → 稳压模块 → Pi 5V/GND 的供电线
   - 确认稳压模块空载输出为 5.0–5.1V
3. **共地线：**
   - 焊接 Pi GND 和 OpenRB-150 GND 的共地连接
4. **IMU 线缆：**
   - 准备 BNO08x 到 Pi 的 4 根线（VIN/3V3, GND, SDA, SCL）
   - 预留适当长度，暂不焊接到 Pi 端（装入壳体后微调长度）
5. **USB 数据线：**
   - 准备一根合适长度的 Micro-USB 数据线连接 Pi 和 OpenRB-150
6. **舵机线缆：**
   - 准备 Dynamixel 3-pin 线缆，按三条链（右腿、左腿、头颈）分组
   - 标记每条链的起始端（连接分线器）

> [!WARNING]
> 暂时不要连接电源开关的最后一段和 IMU 的 Pi 端焊接。这些在电子器件装入壳体后再根据实际走线长度完成。

### 阶段 2 检查清单

- [ ] 电源线路焊接完成，焊点已绝缘
- [ ] 稳压模块输出校准为 5.0–5.1V
- [ ] Pi ↔ OpenRB-150 共地线已焊接
- [ ] IMU 线缆已准备，预留长度待微调
- [ ] 舵机线缆已按三条链分组
- [ ] 所有焊点已用热缩管绝缘

## 阶段 3：舵机预配置 & 预装配关节

> **视频参考：** 以下步骤基于 [Microduck biped build / Dynamixel XL330](https://www.youtube.com/watch?v=Vep8AjoCnEM) 的详细拆解，时间戳已标注。

**目标：** 在将舵机装入 3D 壳体之前完成 ID 分配与零位校准；然后完成关节的机械预装配。

---

### 3-A. 舵机预配置（装壳前必做）[11:05–13:23]

> [!IMPORTANT]
> **必须在装入壳体之前完成 ID 设置和零位对齐。** 装入壳体后更改 ID 或重新对齐舵盘非常困难。

Microduck 使用 **Dynamixel XL330-M288-T** 舵机。所有 XL330 出厂 ID 均为 1，须逐个设置。

#### 方案 A：U2D2 + Power Hub（本仓库默认）

参见 [调试指南 — 一、Dynamixel 舵机 ID 设置](../commissioning/README.md#一dynamixel-舵机-id-设置) 的完整步骤。

#### 方案 B：OpenRB-150 USB 直连（视频作者做法）

如果手头没有 U2D2，也可以使用 OpenRB-150 本身作为接口：

1. 用 USB 线将 OpenRB-150 连接电脑
2. OpenRB-150 的 Dynamixel 端口连接**单个** XL330 舵机
3. 打开 Dynamixel Wizard 2.0，在串口列表中选择 OpenRB-150 对应端口
4. 其余设置步骤与 U2D2 方案一致

> [!TIP]
> 两种方案效果完全一样，区别仅在于硬件接口。OpenRB-150 方案不需要额外购买 U2D2 和 Power Hub。

#### 每个舵机的参数设置

**每次只连接一个舵机**，在 Dynamixel Wizard 2.0 中按如下参数配置：

| 参数 | 地址 | 出厂值 | 目标值 |
| :--- | :---: | :--- | :--- |
| **ID** | 7 | 1 | 按下方 ID 分配表 |
| **Baud Rate** | 8 | 57600 | **1,000,000 (1 Mbps)** |
| **Return Delay Time** | 9 | 250 | **0** |
| **PWM Slope** | 62 | (默认) | **255** |
| **Shutdown** | 63 | (默认) | **去掉 Bit 0 — Input Voltage Error** |

> 去掉 Shutdown 中的输入电压错误触发，是为了避免电池电压波动时舵机误停。

#### 零位对齐（Center）[12:40–13:23]

> [!CAUTION]
> **此步骤决定舵盘与壳体的对齐精度，跳过会导致行走偏斜或关节极限碰撞。**

1. 在 Dynamixel Wizard 中选中该舵机
2. 将 **Torque Enable** 设为 ON
3. 点击 **Center**（Goal Position = 0°），舵机转到物理中位
4. 此时舵盘十字花正好在真正的 0° 位置 — **从这一刻起不要手动转动舵盘**
5. 关闭 Torque，断开舵机，连接下一个

| ID | 名称 | 位置 | 所属链路 |
| :---: | :--- | :--- | :--- |
| 1 | `right_ankle` | 右踝 | 右腿链 |
| 2 | `right_knee` | 右膝 | 右腿链 |
| 3 | `right_hip_pitch` | 右髋俯仰 | 右腿链 |
| 4 | `right_hip_roll` | 右髋横滚 | 右腿链 |
| 5 | `right_hip_yaw` | 右髋偏航 | 右腿链 |
| 6 | `left_ankle` | 左踝 | 左腿链 |
| 7 | `left_knee` | 左膝 | 左腿链 |
| 8 | `left_hip_pitch` | 左髋俯仰 | 左腿链 |
| 9 | `left_hip_roll` | 左髋横滚 | 左腿链 |
| 10 | `left_hip_yaw` | 左髋偏航 | 左腿链 |
| 11 | `head_pitch` | 头部俯仰 | 头颈链 |
| 12 | `neck_pitch` | 颈部俯仰 | 头颈链 |
| 13 | `head_yaw` | 头部偏航 | 头颈链 |

> 建议在每个舵机壳体上贴标签标注 ID 和位置名称（如 "ID3 右髋俯仰"），避免装配时搞混。

### 3-B. 关节结构原理 [3:22–4:13]

Microduck 的关节采用**单侧舵机 + 对侧塑料惰轮环**的结构：

- 舵机安装在关节一侧，舵盘连接下一节结构件
- 对侧使用塑料惰轮环（idler ring）作为支撑轴承

> [!WARNING]
> **M2/M2.5 舵盘螺丝长度至关重要** [2:28, 3:48, 7:25]
>
> - **过短** → 关节在行走中松脱，舵盘从轴上脱落
> - **过长** → 螺丝穿透舵盘底部刺入齿轮板，卡死电机
>
> 安装前用螺丝比对舵盘厚度，确保螺丝穿过舵盘后**不超出底面**。这是视频作者反复强调的 bug。

#### 惰轮环润滑 [3:45, 5:09, 5:23]

- 装配前在塑料惰轮环表面涂抹少量润滑脂（硅脂或白色锂基脂）
- 润滑可大幅降低关节摩擦和异响

> [!CAUTION]
> **不要过度拧紧惰轮板螺丝** [4:10]。拧太紧会使惰轮环被压死，关节无法自由转动。手感到螺丝贴合即可，不要额外加力。

---

### 3-C. 舵机装入壳体

1. 按照打印件和舵机的对应关系，将每个 XL330 舵机推入对应的壳体
2. 注意舵机轴的朝向——轴必须从正确的一侧伸出
3. 将舵机线缆从壳体的线槽中穿出
4. 用 M2 自攻螺丝将舵机固定到壳体

> [!CAUTION]
> **不要过度拧紧自攻螺丝。** PLA 材质的螺纹容易被拧坏，适度拧紧即可。

### 3-D. 舵盘安装

1. 将 Dynamixel 舵盘对准舵机轴 — 舵机已在 3-A 步骤完成零位对齐，舵盘十字花必须对准 0° 位置
2. 用正确长度的 M2 螺丝固定舵盘（参见上方螺丝长度警告）
3. 确认舵盘能顺畅转动，无卡顿
4. 安装对侧惰轮环，涂润滑脂后放入，拧紧惰轮板螺丝（不要过紧）

### 阶段 3 检查清单

- [ ] 所有 14（或 15）个舵机已完成 ID 设置、波特率 1 Mbps、Return Delay 0、PWM Slope 255、Shutdown 去掉输入电压错误

## 阶段 4：主体装配

> **视频参考：** 以下腿部、躯干、颈部和头部装配步骤基于 [Microduck biped build / Dynamixel XL330](https://www.youtube.com/watch?v=Vep8AjoCnEM)，时间戳已标注。

**目标：** 按从下往上的顺序组装足部→腿部→躯干→颈部→头部，然后安装电子器件、布线并整理。

---

### 4-A. 足部与踝关节 [4:40–5:11]

1. 将脚底板（foot base）和脚面盖（foot cover）扣合
2. 将踝关节舵机插入脚部结构：**右脚 = ID 1（`right_ankle`），左脚 = ID 6（`left_ankle`）**
3. 将塑料对位销插入舵机惰轮孔（对侧支撑）
4. 拧入侧面固定螺丝

📷 *[照片占位：脚底板扣合 + 踝关节舵机插入]*

### 4-B. 膝关节与髋俯仰 [5:12–5:40]

1. 为两个惰轮环涂润滑脂
2. 将下一个舵机（膝关节：右 = ID 2，左 = ID 7）滑入小腿支架
3. 将膝关节支架连接到踝关节舵盘上，用螺丝固定
4. 对髋俯仰舵机（右 = ID 3，左 = ID 8）重复上述步骤——滑入大腿支架，连接到膝关节舵盘
5. 两条腿各自独立完成此步骤

📷 *[照片占位：膝关节支架连接到踝关节舵盘]*

### 4-C. 躯干 / 髋横滚 [5:48–7:45]

这是整个装配中最复杂的步骤，涉及多个零件同时配合。

1. **髋横滚舵机安装 [6:10]：** 将两个髋横滚舵机（右 = ID 4，左 = ID 9）安装到中间底板，舵盘穿过底板切口
2. **对侧惰轮 [6:10]：** 在舵机对面安装已涂脂的惰轮环
3. **髋俯仰支架连接 [6:33]：** 将大腿/髋俯仰支架用 4 颗螺丝连接到髋横滚舵盘上（每侧 4 颗）
4. **前盖板安装：** 将前盖板扣到舵盘上
5. **主躯干支架安装 [7:00]：** 将主躯干支架从前方滑入，支架上的卡扣夹住两侧舵机；拧入侧面和顶部螺丝固定
6. **腿部连接 [7:15]：** 将已装好的左右腿分别连接到髋横滚舵盘上，每条腿 4 颗螺丝

> [!WARNING]
> 此处螺丝较多，注意不要遗漏。视频 [7:25] 再次强调了舵盘螺丝长度问题——过长会刺穿到齿轮板。

### 4-F. 电子器件安装 [9:25, 16:28–17:03]

1. **电池安装 [9:30]：**
   - 将 6V 电池放入躯干后部电池仓
   - 视频作者因电池尺寸偏大而切割了部分塑料结构——购买电池前务必对比电池仓尺寸
   - 连接电池到电源开关

2. **OpenRB-150 + Pi 安装 [16:28]：**
   - 将 OpenRB-150 和 Pi Zero 2W 用扎带或胶带固定在电池背面
   - 连接电源线（VIN/GND）到 OpenRB-150
   - 连接 USB 数据线（Pi ↔ OpenRB-150）
   - 连接 5V/GND 供电线到 Pi
   - 确保 Pi Micro-USB 数据口可从外部访问（用于调试和刷写）

3. **IMU 安装 [16:36–16:57]：**

> [!CAUTION]
> **IMU 安装方向至关重要。** BNO085 必须按正确的水平/垂直朝向安装在躯干背面。方向装歪会导致步态偏斜甚至无法站立。

   - 将 BNO08x 模块固定到躯干背面的指定位置
   - 参考上游 [`imu_marker_trunk_views.png`](https://github.com/AI-FanGe/Microduck-build-tutorial/blob/main/mjlab_microduck/imu_marker_trunk_views.png) 严格确认安装方向（水平和垂直轴）
   - 完成 IMU 到 Pi GPIO 的焊接（SDA→Pin3, SCL→Pin5, VIN→Pin1, GND→Pin9）

4. **舵机总线连接：**
   - 连接舵机总线分线器到 OpenRB-150 Dynamixel 端口
   - 将三条链（右腿、左腿、头颈）的舵机 3-pin 线缆按链路顺序串联并连接到分线器

### 4-G. 布线整理 [17:00]

1. 将所有线缆沿躯干内的走线槽布放
2. 用螺旋缠绕管（spiral wrap）收束松散线缆
3. 用小号扎带固定线束，分左右两组

## 阶段 5：校准与调试

**目标：** 在安装外壳之前验证所有电子和机械组件正常工作。

> [!CAUTION]
> **在没有完成校准之前不要安装外壳。** 开壳调试比闭壳调试容易十倍。

详细的校准和调试步骤请参考 [调试指南](../commissioning/README.md)，主要包括：

1. **舵机通信测试：** 上电后检查 OpenRB-150 能否枚举所有 14 个舵机
2. **IMU 检测：** 运行 `i2cdetect -y 1` 确认 BNO08x 地址
3. **首次冒烟测试：** 运行 `main.py`，确认舵机响应和 IMU 数据正常
4. **关节校准：** 在 neutral pose 下确认所有关节角度正确

### 阶段 5 检查清单

- [ ] OpenRB-150 成功枚举 14 个舵机（Dynamixel Wizard 或代码日志确认）
- [ ] `i2cdetect -y 1` 显示 BNO08x 地址
- [ ] `main.py` 冒烟测试通过，舵机正常响应
- [ ] 所有关节在 neutral pose 下角度正确
- [ ] 无异常发热、异响或通信错误

## 阶段 6：合盖与首次行走

**目标：** 安装外壳，进行首次行走测试。

### 合盖

1. 最后检查所有线缆是否安全，无裸露导体
2. 小心地将外壳盖上，确保不夹住任何线缆
3. 用 M2 自攻螺丝固定外壳

> [!CAUTION]
> 合盖时动作要轻柔，避免压到线缆造成短路或断线。

### 首次行走测试

1. 将 microSD 卡刷写好镜像并插入 Pi（参考 [上游 README](https://github.com/AI-FanGe/Microduck-build-tutorial#使用-microduckimgxz)）
2. 配置 Wi-Fi
3. 上电，等待 1–3 分钟启动
4. SSH 登录：
   ```bash
   ssh user@microduck.local
   ```
5. **手扶机器人**，启动控制程序：
   ```bash
   cd ~/microduck
   PYTHONPATH=src .venv/bin/python src/main.py
   ```
6. 按 `v` 开启行走，观察步态是否正常

> [!CAUTION]
> **第一次行走必须手扶机器人！** 不要在桌边或高处测试。确认步态稳定后再尝试放手。
